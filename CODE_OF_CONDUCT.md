# Community conduct

Memail welcomes contributors and self-hosters with different backgrounds and
experience. Discuss behavior and code respectfully, explain disagreements,
and help others reproduce problems without blaming them.

Harassment, threats, discrimination, impersonation, spam and publication of
another person's private information are not accepted. Keep real mail,
credentials and personal account details out of public reports.

Maintainers may edit or remove abusive content, lock discussions, or restrict
participation when needed, and should explain moderation decisions where
doing so does not disclose private information. Reports about conduct should
use the private contact channels listed on the Saivra or maintainer GitHub
profile; do not publish sensitive reports in an issue. Security reports use
[SECURITY.md](SECURITY.md).
