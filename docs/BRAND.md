# Memail identity

Memail's mark combines an M with the fold of an envelope. Its forest and warm
ivory palette matches the Memail workspace. The small mint fold remains an
accent; the monogram must remain recognizable in one color.

- [Light mark](../public/branding/memail/mark.svg)
- [Dark mark](../public/branding/memail/mark-dark.svg)
- [Light wordmark](../public/branding/memail/wordmark.svg)
- [Dark wordmark](../public/branding/memail/wordmark-dark.svg)

Use the mark for favicons, compact navigation and application icons. Use the
wordmark where the product name is not already shown. Keep one quarter of the
mark's width clear around standalone uses. Do not stretch it, add effects,
change the letter construction or place it on a low-contrast background.

Forest: `#1d4534`; ivory: `#f0f5e8`; mint: `#9bceb0`. Assets are original,
code-native SVGs; PNG/PWA sizes are rendered from these sources. Rebuild them
with `node .memail/build-brand.mjs`.

Deployment branding and domain overrides remain supported. Memail defaults
must not overwrite an administrator's custom identity. Bulwark assets remain
in the repository for attribution/history and compatible custom references.
